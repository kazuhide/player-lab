# 記録した検証結果

[English](validation.md) · [日本語](validation.ja.md)

2026年10月28日に、Player Android 3.172.0と統合Analytics collector 3.35.2で実行した結果です。端末再生には本リファレンスの自作素材とローカルに設定したPlayerライセンスを使いました。認証情報、端末の識別番号、非公開の配信元、端末の生ログは含めていません。

アクセシビリティの確認では実際のラベル、フォーカス、表示範囲、タッチ領域を調べています。スクリーンリーダーの読み上げ音声は測定していません。仮想端末の全テストはホストへ接続するアドレスを使い、ローカル素材サーバーへ接続しました。実機のクラウドVOD再生では、エンコードが完了した映像と、元データに基づく外部字幕ファイルを使いました。ファイルのバイト列を変更しないループバックのゲートウェイへ、USB転送で接続しています。これらの結果から、CDNへの直接接続、クラウドLiveの録画、クラウドのマスターに字幕トラックの宣言がない場合のHLS登録字幕までは確認できません。

## Analytics照会の実例

ダッシュボードは2026年10月28日04:06 UTCに、本アプリのAndroid教材IDを対象として実際のAnalyticsサービスへ照会しました。選択した期間は10月27日04:06 UTCから10月28日04:06 UTCまでです。

| 指標 | 返された値 |
| --- | --- |
| 再生開始数 | 2 |
| 視聴時間 | 0.00189639時間 |
| 再生開始までの時間の中央値 | 2.073秒 |
| 再生開始までの時間の95パーセンタイル | 2.073秒 |
| 再バッファ割合 | 0% |
| エラー率 | 0% |

この少量のデータは照会と単位換算の例です。性能比較ではありません。その後の端末テストでは、さらに再生セッションが作成されています。サーバーの取得時刻は集計結果を受信した時刻を示し、最新の生データが到着した時刻ではありません。

## 同じ確認を実行する

[設定と端末テストのコマンド](../README.ja.md#check-the-application)に従ってください。端末ドライバーは実際の実行件数、ランナーの終了状態、APKのハッシュを、Git管理対象外の`android/build/device-tests/`へ記録します。強制停止の確認には全テストを使ってください。再起動の一段階だけを実行しても、プロセス終了後の復元は確認できません。

[素材の測定記録](../fixtures/local-media-validation.json)はローカルで生成したファイルの記録です。クラウドエンコードとクラウド素材の再生は、それぞれ別の確認です。アップロードの完了やジョブの登録だけでは、再生できたことにはなりません。

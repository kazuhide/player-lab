# Web で教材を再生する

[English](README.md) · [日本語](README.ja.md) · [素材の準備](../README.ja.md)

Bitmovin Player Web 8.284.0 と UI 4.23.1 を使います。カタログ、映像 ID、再生素材はネイティブアプリと共通です。ブラウザーの言語設定に合わせて英語または日本語で表示します。

## ローカルで起動する

[素材の準備](../README.ja.md)に従って、このアプリの素材を生成し、配信サーバーを起動してください。カタログの既定の URL は `http://127.0.0.1:8621/catalog.json` です。Node.js 24.19 以降を使い、このディレクトリで次のコマンドを実行します。

```sh
npm ci
cp .env.example .env.local
```

`VITE_PUBLIC_PLAYER_LICENSE_KEY` に、`localhost` での再生を許可した Player ライセンスを設定してください。素材の配信元を変更した場合は、`VITE_MEDIA_BASE_URL` に配信元ディレクトリの URL を設定します。再生品質を計測する場合は、`VITE_PUBLIC_ANALYTICS_LICENSE_KEY` にデモ用の Analytics ライセンスを設定してください。これらの設定値はブラウザーから読み取れます。アカウントの API キーは分析画面のサーバーだけに設定します。

```sh
npm run dev
```

`http://localhost:5181` を開いてください。環境設定を変更した場合は開発サーバーを再起動します。静的に配信する場合は、視聴端末から到達できる素材の URL を指定して `npm run build` を実行し、ライセンスで許可したホストから `dist/` を配信してください。HTTPS のページから再生する場合は、素材の配信元も HTTPS にして CORS を有効にします。

## 再生する

コースが複数ある場合は、先にコースを選んでください。「前へ」「次へ」と自動再生は、選んだコースの教材順に進みます。利用者を切り替えると、その人が最後に選んだコースに戻ります。ページを再読み込みすると、最初のコースから始まります。

利用者AまたはBを選び、配信形式と次の教材に自動で進むかを決めます。再開位置がある教材を開くと、続きから再生するか先頭から再生するかを選べます。アプリは素材の実際の長さを確認してから再開位置に移ります。再開位置、速度、字幕、UI モード、連続再生の設定は、利用者と教材ごとにブラウザーに保存します。自動で次へ進むかどうかは、コースを開く際の選択が適用されます。利用者を切り替えると再生が終了し、その利用者の設定と診断ログがメモリーから消去されます。

学習用UIでは10秒ずつ進めたり戻したりできます。どちらのUIでも教材一覧と英語・日本語の本文検索を使えます。字幕がオフでも、検索結果を選ぶとその文の開始位置に移動します。HLS ではマニフェスト内の字幕または外部字幕を選べます。DASH は外部字幕を使います。配信形式や連続再生の設定を変更するときはコースに戻ってください。

本文は最初、再生中の行に合わせてスクロールします。検索中は自動スクロールが止まります。タッチ、ホイール、キーボードで本文を移動した場合も、自動スクロールはオフになります。再生に合わせて読み進めるには、自動スクロールを再びオンにしてください。

再開を選ぶ画面でも、次の教材に自動で進むかを変更できます。「再開」または「最初から」を選んだ時点の設定が適用されます。読み込み中にタブを隠すと、自動では再生を始めません。一時停止中のタブを閉じた場合や、別のタブで同じ教材を最後まで見た場合にも、ほかのタブで更新した新しい再開位置は保持されます。

UI を切り替えても同じ Player、Source、字幕レンダラー、Analytics セッションを使います。アプリの操作画面では、ブラウザーが対応していれば全画面表示に切り替えられます。SDK が対応する環境では、ピクチャ・イン・ピクチャへの切り替えや AirPlay の出力先の選択もできます。診断画面には映像 ID と数値のエラーコードを含む直近30件までの SDK イベントを表示します。

## 確認する

```sh
npm test
npm run build
```

Google Chrome を用意し、生成済みの素材を配信して、ライセンスを設定したアプリを起動します。その状態でブラウザーテストを実行してください。

```sh
FORMAT=hls npm run test:browser
FORMAT=dash npm run test:browser
```

macOS の WebKit で HLS 再生を確認する場合は、`npx playwright install webkit` で Playwright の WebKit をインストールし、`BROWSER=webkit FORMAT=hls npm run test:browser` を実行してください。別のポートで起動したアプリを確認するには `APP_URL` を設定します。

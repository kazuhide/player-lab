Open Web app User guide

A Bitmovin Player playground for the Web, with examples for iOS, Android, React Native, and Vega OS. Start with the existing player controls and see how a setting changes playback.

Web features

The interface and its code stay together, so experiments are easy to follow.

Configure playback
Change player settings, source settings, and advanced tweaks in the onscreen panels. Each setting indicates whether it applies immediately, reloads the source, or recreates the player.
Themes and construction code
Compare the standard interface, styles made with Cascading Style Sheets (CSS), and custom component layouts. The construction panel shows the code for the selected theme.
Inspect real playback
Try live rewind, audio selection, subtitles, and thumbnail previews. Player state, events, and local playback measurements help explain the result. The Pages version includes media for the feature examples.

Run the Web app

Use Node.js 24.19.0 and pnpm 10.33.0, then run these commands.

Open the printed URL with the hostname localhost to run the Web Player without a key. The public Player license must allow kazuhide.github.io; its client key is delivered to the browser. Other hosts and native apps also need an allowed license.

Setup and optional media 
git clone https://github.com/kazuhide/player-lab.git
cd player-lab
pnpm install --frozen-lockfile
pnpm --filter @showcase/web dev

Platform examples

Each example keeps its platform's player and toolchain. The platform guides describe supported formats, license setup, and verification limits.

The apps use several test streams. Pages includes short Big Buck Bunny clips; local and native apps also use external reference streams. Available audio, subtitles, and live rewind ranges depend on the source. See test sources, test results, and media credits.

Analytics and Observability

The Analytics collector sends playback events from the player. Review the collected data in Bitmovin Dashboard to inspect playback quality and usage. The guide explains Dashboard views, collected metrics, API queries, external visualization, and analysis with a language model.

The app's QoE panel shows startup time, buffering, and related values for the current browser session. These local readouts are separate from the data available in Bitmovin Dashboard.

Analytics aggregation queries need a backend and are hidden on Pages. They are available through the local Web server with the appropriate API access.

The public Analytics license must allow kazuhide.github.io. Its client key is delivered to the browser.

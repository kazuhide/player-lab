Bitmovin Playerの検証用サンプル

Web版には設定パネルと再生操作用のボタンがあります。 操作画面のテーマを選択し、その画面を構成するコード例を確認できます。

Web版を開く ユーザーガイド

Web、iOS/tvOS、Android/Fire TV、React Native、Vega OS向けの実装を含みます。 対応機能と必要な開発環境は各プラットフォームのガイドに記載しています。

Web版の機能

設定の編集、操作画面の切り替え、再生状態の確認を同じ画面で行います。

プレイヤーと配信ソースの設定
PlayerConfig（プレイヤー全体の設定）、SourceConfig（読み込む動画の設定）、 TweaksConfig（詳細調整）の一部の項目をパネルから変更できます。自動再生、初期音量、バッファー量、 動画のタイトル、ポスター画像、再生開始位置などを変更できます。 適用方法は項目ごとに表示します。プレイヤーの再作成、動画の再読み込み、再生中の反映の3種類があります。
テーマとコード例
標準の操作画面1種類、CSSで外観を変更した5種類、部品の構成を変更した8種類があります。 CSSは色や余白などの表示を指定するために使います。 テーマを選択すると対応するコード例と説明をプレイヤーの横に表示します。
再生操作と状態の確認
画面上のボタンや選択欄から再生・一時停止、再生位置の移動、再生速度の変更、 画質・音声・字幕の選択を実行します。これらの操作にはプレイヤーのAPI（アプリから機能を呼び出す仕組み）を使います。 ライブ配信では巻き戻し可能な範囲と現在位置を表示します。プレイヤーが通知するイベントも記録します。 再生開始までの時間や再生中にデータの読み込み待ちが発生した回数などをブラウザー内で測定して表示します。 Pages版には複数音声、外部字幕、プレビュー画像のテスト素材を含みます。 手元で起動する場合は、対応する素材のURLを別途設定します。

Web版の起動手順

Node.js 24.19.0とpnpm 10.33.0を使用します。リポジトリを取得した後、 依存パッケージをインストールして開発サーバーを起動します。

起動後に表示されるURLをブラウザーで開きます。ホスト名がlocalhostの場合はWeb Playerをライセンスキーなしで実行できます。 Pages版に組み込むPlayerとAnalyticsのライセンスにはkazuhide.github.ioを許可登録します。 どちらのキーもブラウザーへ配信されます。 その他のホスト名やiOS・Androidなどのアプリでも、利用するドメイン名またはアプリ識別子を登録したライセンスを使用します。

ライセンスと設定手順 
git clone https://github.com/kazuhide/player-lab.git
cd player-lab
pnpm install --frozen-lockfile
pnpm --filter @showcase/web dev

再生テストと検証記録

Pages版にはBig Buck Bunnyから生成した60秒分の素材を含みます。 動画を分割して配信するHLS・DASH形式に対応し、映像は2秒ごとに分割します。 再生、画質・音声の選択、字幕、プレビュー画像などがテストの対象です。

2つの音声トラックは同じ音源を異なる音量で収録しており、言語名はテスト用の識別情報です。 字幕はSintelのテキストを使って表示タイミングを確認するための素材で、Big Buck Bunnyの翻訳ではありません。

ブラウザー内で測定する再生開始時間や読み込み待ちの回数は確認できます。 Analyticsのライセンスを設定した場合は、再生データをBitmovinへ送信します。 集計クエリはサーバー側の処理が必要なため、Pages版では無効です。

ブラウザーでの再生テスト、アプリのビルド（ソースコードからアプリを作成する処理）、 iOSシミュレーターやAndroidエミュレーターでの実行は別々に記録しています。 テスト結果には実行環境、使用素材、確認した操作、未検証の項目を記載しています。

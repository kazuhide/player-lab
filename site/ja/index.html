プレイヤーの設定と見た目を、手軽に試す。

テーマを切り替え、プレイヤーや再生する動画の設定を変更。 操作画面を組み立てるコードも、その場で確認できます。

手元で起動する Web ガイド（英語）

Bitmovin Player を使った Web 向けの実験用アプリです。 iOS、Android、React Native、Vega OS のサンプルも用意しています。 既存の操作画面で設定を変え、再生への効果を確かめられます。

設定を変える。
再生で確かめる。

操作画面とコードを一緒に見ながら試せます。

再生の設定を変える
画面上のパネルから、プレイヤーや再生する動画の設定、高度な調整項目を変更できます。 変更をすぐ反映するのか、動画を読み直すのか、プレイヤー自体を作り直すのかが分かります。
14種類の操作画面を比べる
標準の画面、CSS（画面の見た目を指定する仕組み）で整えたデザイン、 部品の配置を変えた画面を比較できます。選んだテーマの組み立てコードも表示します。
実際の再生を調べる
ライブ配信の巻き戻し、音声の切り替え、字幕、再生位置のプレビュー画像を試せます。 プレイヤーの状態や動作の記録、再生状況の測定値を確認できます。 追加のサンプルには必要な素材を明記しています。

手元で起動する。

Node.js 24.19.0 と pnpm 10.33.0 を用意し、次のコマンドを実行します。

ブラウザーで開くアドレスのホスト名には localhost を使ってください。 このホスト名では、Web Player をライセンスキーなしで試せます。 別のホスト名や端末向けアプリでは、ご自身のライセンスが必要です。

設定と追加のテスト素材（英語） 
git clone https://github.com/kazuhide/player-lab.git
cd player-lab
pnpm install --frozen-lockfile
pnpm --filter @showcase/web dev

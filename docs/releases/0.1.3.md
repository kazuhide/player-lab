# Player Lab 0.1.3

The English and Japanese implementation guides now provide separate pages for
integration, PlayerConfig / SourceConfig, UI customization, playback features
and events, FAQ, and Analytics / Observability.

Each platform keeps Screen and controls and Implementation guide as its
unnumbered entry points. The implementation overview links to its sections;
the contents expands that platform's implementation pages while you read them.
Code examples and screen captures remain beside the relevant explanations.

Platform-specific subheadings cover native presentation and system integration,
offline playback, ownership and lifecycle, React Native hosts, and Vega media
and remote controls where those topics apply. The guide continues to use the
existing applications as its reference. Player behavior and SDK versions are
unchanged.

Search results open the relevant implementation page. Published overview URLs,
section bookmarks, and detailed Web guide URLs remain usable. Each section
links back to its overview, the app's controls, and shared reference material.

Read the [English guide](https://kazuhide.github.io/player-lab/guide/)
or the [Japanese guide](https://kazuhide.github.io/player-lab/ja/guide/).

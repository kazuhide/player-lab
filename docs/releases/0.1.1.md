# Player Lab 0.1.1

This documentation update adds an implementation guide alongside the existing
operation chapters. Player behavior and SDK versions are unchanged.

## Read the implementation

- Follow Player creation, source loading, configuration changes, UI composition
  and event cleanup in the existing Web app.
- Trace Player ownership, native views, configuration and source loading in the
  iOS/tvOS, Android, React Native and Vega implementations.
- Read Analytics / Observability as the final section, from collector
  configuration to finding the corresponding session in Bitmovin Dashboard.
- Open the public source beside each code excerpt. The English and Japanese
  guides use the same excerpts, and automated checks compare them with the
  referenced repository lines.

The existing operation chapters, screenshots, settings references and bookmarks
remain available. The native overview now reflects the implemented offline
inspectors and platform integration controls.

Read the [English implementation guide](https://kazuhide.github.io/player-lab/guide/implementation/)
or the [Japanese implementation guide](https://kazuhide.github.io/player-lab/ja/guide/implementation/).
No configuration migration is required. Existing license, media and device
requirements still apply; see the [0.1.0 scope](0.1.0.md#scope).

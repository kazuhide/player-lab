# Player Lab 0.1.5

This release improves settings workflows, configuration comparisons and API
discovery across the Web and native samples, with updated English and Japanese
guides.

## Settings and API discovery

- Android, Apple and React Native provide direct setting selection, fixed Apply
  and Reset actions, and Settings, APIs, Code and More workspaces. Drafts and the
  player survive navigation and layout changes. Editors keep actions reachable
  with large text and software keyboards. TV controls improve remote focus;
  tvOS Back/Menu returns from an editor to the workspace tabs.
- Native interfaces support English and Japanese while retaining the original
  SDK identifiers, source values, returned data and code. React Native keeps
  configuration navigation available after input and handler-factory errors.
- Web drafts survive search, selection and language changes. Apply waits for the
  SDK result and keeps failed drafts available for correction. Before values
  continue to show the last successful Apply. Failures without an SDK message receive an
  explicit error description.
- Web and React Native show Before and After configuration values. Sensitive
  fields use placeholders in comparisons and generated configuration. Copied Web
  code preserves applied values and serializes SDK enums correctly.
- API search on Web, React Native and Vega puts exact API paths and method names
  first. Vega's Previous results and Next results controls reach every match.
- The public Live HLS sample has been replaced. Apple retains initial audio and
  subtitle preferences when changing themes or reloading a source.

## Guides and development tools

The guides add collapsible section navigation, clearer instructions and current
captures of the English and Japanese interfaces. Standalone integration examples
are checked against the pinned SDKs and include platform setup and host-entry
instructions. SDK update checks, sanitized browser failure diagnostics and
managed local previews also improve source development.

Read the [English guide](https://kazuhide.github.io/player-lab/guide/) or
[Japanese guide](https://kazuhide.github.io/player-lab/ja/guide/).

## Updating a source checkout

Bitmovin SDK version pins are unchanged from 0.1.4. The Android shared Gradle
module is now `:playback`, replacing `:dvr`. The Apple Swift package and module
are now `PlaybackCore`, replacing `DvrKit`. Update local module references,
imports and test commands that used those names.

Refresh dependencies and generated resources using the tagged platform
instructions. Regenerate the Apple Xcode project and React Native / Expo host,
then rebuild the native apps:

- [Apple setup](https://github.com/kazuhide/player-lab/blob/v0.1.5/apps/ios/README.md)
- [Android setup](https://github.com/kazuhide/player-lab/blob/v0.1.5/apps/android/README.md)
- [React Native / Expo setup](https://github.com/kazuhide/player-lab/blob/v0.1.5/apps/react-native/README.md)
- [Vega setup](https://github.com/kazuhide/player-lab/blob/v0.1.5/apps/vega/README.md)

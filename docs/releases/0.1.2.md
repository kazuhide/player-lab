# Player Lab 0.1.2

This release expands the English and Japanese implementation guides for people
integrating or evaluating Bitmovin Player.

## Platform guides

The Web section keeps its screen and theme comparison, source and track controls,
and UI settings before the implementation guide. PlayerConfig / SourceConfig and
UI customization have detailed child chapters.

iOS / iPadOS / tvOS, Android / Android TV / Fire TV, React Native and Vega OS each
have an independent implementation guide and a screen-and-controls chapter.
The implementation guides explain configuration scope and application, UI changes,
useful features and common problems before Analytics / Observability. They link
to the existing app's source and show its configuration and inspection screens.

## Navigation

Platform topics are nested in the contents, and implementation pages provide
links to their own sections. Existing combined chapter URLs and section bookmarks
lead readers to the corresponding platform guides. Guide search includes FAQ
questions as well as answers.

## Scope

The player implementations and SDK versions are unchanged. This release updates
the guide, its navigation and checks, and the product version shown in builds.
Device and media requirements still apply to features such as Cast, protected
playback, offline playback and SharePlay; the guides describe these separately
from the controls exposed by the app.

Read the [English guide](https://kazuhide.github.io/player-lab/guide/)
or the [Japanese guide](https://kazuhide.github.io/player-lab/ja/guide/).

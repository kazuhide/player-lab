# Player Lab 0.1.2

This release expands the English and Japanese implementation guides for people
integrating or evaluating Bitmovin Player.

## Platform guides

Web, iOS / iPadOS / tvOS, Android / Android TV / Fire TV, React Native and Vega OS
each have Screen and controls followed by Implementation guide, without numbered
chapter lists. Screen and controls explains the app workflow with captures beside
the relevant steps: select a source, apply settings, compare UI, read applied code
and inspect SDK operations, state and events.

The implementation guides explain PlayerConfig / SourceConfig, reusable code,
UI customization, useful features and common problems before Analytics /
Observability. They link to the existing app's source. Web configuration, UI
attachment, CSS and component-composition examples are included in its guide.

## Navigation

The contents uses the same chapter pair for each platform. Each chapter provides
links to its own sections. Existing combined and detailed Web chapter URLs and
section bookmarks remain usable. Guide search includes FAQ questions as well as
answers. Guide captures can be opened at their original size.

## Scope

The player implementations and SDK versions are unchanged. This release updates
the guide, its navigation and checks, and the product version shown in builds.
Device and media requirements still apply to features such as Cast, protected
playback, offline playback and SharePlay; the guides describe these separately
from the controls exposed by the app.

Read the [English guide](https://kazuhide.github.io/player-lab/guide/)
or the [Japanese guide](https://kazuhide.github.io/player-lab/ja/guide/).
